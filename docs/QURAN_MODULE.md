# Module Coran — AEEMG

Coran complet intégré (style Muslim Pro), **100 % hors ligne**.

## Contenu

- **114 sourates** — texte arabe (Uthmani) + traduction française (Hamidullah)
- **30 Juz** — lecture par partie
- **Signets** — versets favoris (stockage local)
- **Reprise** — « Continuer la lecture »
- **Recherche** — par nom de sourate ou mot dans la traduction française
- **Récitation audio** — 9 récitateurs (Al-Afasy, Husary, Ajamy, etc.) via CDN islamic.network
- **Mode Mushaf** — 604 pages, défilement horizontal, reprise de page

## Accès dans l'app

- Onglet **Mosquée** → carte « Coran complet »
- **Profil** → Coran complet
- **Accueil** → tap sur le verset du jour

## Package

[`quran`](https://pub.dev/packages/quran) — données embarquées, pas de réseau requis.

## Audio

- Nécessite une connexion internet (streaming)
- Choisir le récitateur : icône micro dans l'écran Coran ou lecteur de sourate
- Écouter une sourate entière ou verset par verset

## Mushaf

- Onglet **Mushaf** → 604 pages officielles
- Swipe gauche/droite pour naviguer
- Icône épingle pour sauter à une page
